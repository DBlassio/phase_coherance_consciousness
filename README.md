# Phase Coherence & Consciousness Under LSD

A dynamic functional connectivity pipeline to explore how LSD reshapes conscious brain states. Built in Python using NumPy, SciPy, Scikit-learn, and Matplotlib, this repo contains everything from processing fMRI timeseries to generating chord diagrams and computing entropies. You’ll find well-documented code and intuitive visualizations designed for rapid understanding and easy extension.

---

## 🚀 Quick Overview

1. **Process fMRI timeseries** (z-scoring, Hilbert transform)  
2. **Compute phase coherence matrices** at each timepoint  
3. **Vectorize** those matrices for clustering  
4. **Run k-means** to identify 5 canonical brain states  
5. **Calculate occupancy, Shannon entropy, Markov-chain entropy**  
6. **Visualize** state coherence via chord diagrams  

All scripts are modular: feel free to swap in your own dataset or tweak clustering parameters. The end goal? To reveal how LSD pushes the brain toward new dynamic configurations without sacrificing overall flexibility.
